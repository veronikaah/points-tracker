# Score Keeper CLI (Points Tracker)

A lightweight Python Command-Line Interface (CLI) application designed to keep track of scores for card games, board games, or any group activity. 

It supports customizable winning conditions (highest or lowest score wins), dynamic player registration, and displays sorted leaderboard rankings at the end of the game.

---

## Features

* **Flexible Game Modes:** Choose between two win conditions:
  * **Highest Points Win**
  * **Lowest Points Win**
* **Dynamic Player Setup:** Add as many players as you need with built-in validation for duplicate or empty names.
* **Round-by-Round Tracking:** Simply enter points for each player at the end of every round.
* **Final Leaderboard:** Automatically calculates and displays ranked placements upon game completion.
