# Roulette CLI

An interactive Python command-line application that allows users to dynamically manage a custom list of options and randomly spin for a selected result.

## Features
* **Custom Option Management:** Easily add multiple options line by line in the terminal.
* **Flexible Modes:** Supports standard random selection as well as a deletion mode (`delete_mode`) that removes drawn items.
* **Input Validation:** Robust handling of user inputs and empty state checks.

## Technologies
* Python 3
* Built-in `random` module
